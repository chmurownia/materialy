# Instrukcja Startowa (Do wykonania w domu PRZED zajęciami!)

Abyśmy na lekcji mogli od razu przejść do pracy nad projektem, musisz przygotować swoje środowisko pracy. Zrób to spokojnie w domu.

## Krok 1: Założenie konta na GitHubie

GitHub to Twoja wizytówka w świecie IT. Założenie konta jest darmowe.

1. Wejdź na stronę: **[https://github.com](https://github.com)** i kliknij przycisk **Sign up** w prawym górnym rogu.
2. Wpisz swój adres e-mail (najlepiej użyj swojego prywatnego adresu lub szkolnego, do którego masz stały dostęp).
3. Ustal silne hasło.
4. Wybierz nazwę użytkownika (Username). Pamiętaj: ta nazwa będzie widoczna w linkach do Twoich przyszłych projektów i potencjalnie w Twoim CV. Najlepiej użyć kombinacji imienia i nazwiska (np. `jankowalski`, `jan-kowalski-it`). Unikaj pseudonimów z gier (np. `Terminator2000`).
5. Rozwiąż obrazkową zagadkę CAPTCHA, aby udowodnić, że nie jesteś botem.
6. Na podany adres e-mail otrzymasz kod weryfikacyjny. Przepisz go na stronie GitHuba, aby aktywować konto.

**Ważne:** Zapisz swoje hasło w bezpiecznym miejscu (np. w menedżerze haseł) – będziesz musiał zalogować się na to konto na komputerze w sali szkolnej!

## Krok 2: Instalacja Git Bash (Tylko dla systemu Windows)

*Jeśli pracujesz na szkolnym komputerze, upewnij się u nauczyciela, czy ten program nie jest już zainstalowany. Jeśli pracujesz na własnym laptopie z systemem Windows, wykonaj poniższe kroki.*

Git Bash to aplikacja, która instaluje system kontroli wersji (Git) na Twoim komputerze i daje Ci dostęp do konsoli (terminala), z której korzystają profesjonalni programiści.

1. Wejdź na stronę: **[https://git-scm.com/downloads](https://git-scm.com/downloads)** i kliknij w ikonę "Windows", a następnie pobierz wersję (zazwyczaj "64-bit Git for Windows Setup").
2. Uruchom pobrany plik instalacyjny (`.exe`).
3. Instalator zapyta Cię o kilka technicznych szczegółów. **Nie musisz niczego zmieniać.** Klikaj po prostu `Next`, aż instalacja się zakończy. Domyślne ustawienia są dla nas w pełni wystarczające.
4. (Opcjonalnie) Jeśli korzystasz z systemu macOS, Git zazwyczaj jest już zainstalowany (lub zainstaluje się sam, gdy pierwszy raz otworzysz aplikację Terminal i wpiszesz komendę `git`). Na Linuksie używasz menedżera pakietów (np. `sudo apt install git`).

## Krok 3: Weryfikacja instalacji

Aby upewnić się, że wszystko działa:

1. Kliknij przycisk Start (w Windows), wpisz `Git Bash` i uruchom aplikację. Otworzy się czarne okienko terminala.
2. Wpisz komendę: `git --version` i wciśnij Enter.
3. Jeśli w odpowiedzi zobaczysz wersję programu (np. `git version 2.41.0.windows.1`), oznacza to, że jesteś gotowy do zajęć!
