# 2. GitHub Student Developer Pack

*Krok 2 z 6.* Darmowy pakiet narzędzi dla uczniów i studentów.

## Jak go włączyć

1. Zaloguj się na GitHub i dodaj **adres e-mail szkolny** w *Settings → Emails* oraz go zweryfikuj. Uzupełnij też prawdziwe imię i nazwisko w profilu.
2. Wejdź na [education.github.com/pack](https://education.github.com/pack) i kliknij **Join GitHub Global Campus** / **Get student benefits**.
3. Wybierz status **Student** i wyszukaj swoją szkołę.
4. Zezwól przeglądarce na lokalizację (GitHub porównuje ją ze szkołą) i dodaj dowód uczenia się: zdjęcie legitymacji szkolnej lub zaświadczenie z datą i nazwą szkoły.
5. Wyślij wniosek. Weryfikacja trwa od kilku minut do kilku dni – dostaniesz e-mail z decyzją. Jeśli wniosek odrzucono, popraw dane i spróbuj ponownie.
6. Po akceptacji benefity aktywujesz w [Global Campus](https://education.github.com/globalcampus/student). Dostęp trzeba odnawiać co 1–2 lata.

*Wymagania mogą się zmieniać (np. minimalny wiek 13 lat) – aktualne zasady znajdziesz na stronie programu.*
