# 1. Jak założyć konto na GitHub

*Krok 1 z 6.* Konto jest darmowe i zajmuje kilka minut.

1. Wejdź na [github.com/signup](https://github.com/signup).
2. Podaj adres e-mail (najlepiej taki, do którego masz stały dostęp – np. szkolny, przyda się do Student Developer Pack).
3. Wymyśl hasło (min. 8 znaków, najlepiej długie i unikalne) oraz nazwę użytkownika, np. `jan-kowalski`. Będzie widoczna w adresie Twojej strony.
4. Rozwiąż zadanie weryfikacyjne (puzzle), aby potwierdzić, że nie jesteś robotem.
5. Wpisz kod weryfikacyjny, który GitHub wyśle na Twój e-mail.
6. Wybierz plan **Free** – w pełni wystarczy na początek.
7. Włącz uwierzytelnianie dwuskładnikowe: *Settings → Password and authentication → Two-factor authentication*.

!!! tip "Wskazówka"

    Uzupełnij profil (zdjęcie, imię, krótki opis) – to Twoja wizytówka w świecie IT.
